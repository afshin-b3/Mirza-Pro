# ربات میرزا پرو و اسکریپت مدیریت
این ریپازیتوری شامل پروژه اوپن‌سورس **ربات میرزا پرو** است که همراه با یک اسکریپت قدرتمند برای نصب و مدیریت خودکار ارائه شده است.

<p align="center">
  <img src="https://raw.githubusercontent.com/afshin-b3/Mirza-Pro/main/Banner.jpg" alt="بنر ربات میرزا پرو" width="600"/>
</p>

## 🎉 پروژه نسخه پرو، اوپن‌سورس شد!
نسخه‌ی **Pro** این پروژه اکنون به‌صورت **اوپن‌سورس** در دسترس است!  
از مشارکت، پیشنهادها و همکاری شما برای توسعه‌ی بهتر پروژه استقبال می‌کنیم 🤝

#### 📜 درباره این اسکریپت
این ریپازیتوری یک اسکریپت قدرتمند bash برای ساده‌سازی تمام چرخه عمر ربات میرزا پرو ارائه می‌دهد. از نصب کامل گرفته تا پشتیبان‌گیری منظم و حذف آسان، این اسکریپت همه کارها را برای شما انجام می‌دهد.

#### ✨ قابلیت‌ها
*   **نصب خودکار:** نصب ربات، وب‌سرور (آپاچی)، PHP، دیتابیس MySQL و امن‌سازی با گواهی SSL رایگان (Let's Encrypt).
*   **مدیریت پشتیبان‌گیری:**
    *   ایجاد بکاپ دستی از دیتابیس (`.sql`) و فایل‌های سورس (`.tar.gz`).
    *   ارسال مستقیم بکاپ‌ها به یک کانال یا چت خصوصی تلگرام.
    *   پیکربندی زمان‌بندی بکاپ خودکار (روزانه، هفتگی، سفارشی).
*   **حذف آسان:** حذف کامل تمام اجزای ربات، شامل فایل‌ها، دیتابیس، تنظیمات وب‌سرور و کرون‌جاب‌ها.
*   **تمدید گواهی SSL:** یک دستور ساده برای تمدید گواهی SSL.
*   **منوی تعاملی:** یک منوی کاربرپسند برای دسترسی به تمام قابلیت‌ها.

#### 🚀 روش نصب
برای نصب ربات با استفاده از اسکریپت مدیریت، دستور زیر را به عنوان کاربر root اجرا کنید:

```bash
bash <(curl -s https://raw.githubusercontent.com/afshin-b3/Mirza-Pro/main/install.sh)
```

**گزینه‌های منو:**
1.  **نصب / نصب مجدد ربات:** فرآیند نصب کامل را اجرا می‌کند.
2.  **مدیریت پشتیبان‌گیری:** وارد زیرمنوی بکاپ می‌شود.
3.  **تمدید گواهی SSL:** گواهی SSL را تمدید می‌کند.
4.  **حذف ربات:** ربات و تمام اجزای آن را به طور کامل حذف می‌کند.
5.  **خروج:** از اسکریپت خارج می‌شود.

#### ⚠️ نکات مهم برای کاربران
برای اطمینان از نصب موفق، لطفاً اطلاعات زیر را به درستی وارد کنید:

*   **دامنه:** دامنه یا ساب‌دامین خود را **بدون** `http://` یا `https://` وارد کنید (مثال: `bot.yourdomain.com`).
*   **توکن ربات تلگرام:** مطمئن شوید که توکن کامل و صحیح را از BotFather کپی کرده‌اید.
*   **آیدی عددی ادمین:** این مقدار باید **آیدی عددی** شما باشد، نه نام کاربری. آن را از ربات‌هایی مانند `@userinfobot` دریافت کنید.
*   **آیدی چت بکاپ:** برای کانال‌های خصوصی، این آیدی معمولاً با `-100` شروع می‌شود. ربات شما باید در آن کانال **ادمین** باشد و دسترسی ارسال پیام را داشته باشد.
*   **نسخه پنل مرزبان:** اگر از پنل مرزبان نسخه **0.8.4 یا پایین‌تر** استفاده می‌کنید، باید به سوال `Are you using the NEW Marzban panel?` پاسخ **`no`** بدهید. برای نسخه‌های جدیدتر، پاسخ **`yes`** را وارد کنید.
